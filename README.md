# Sistema DND

Motor de combate por turnos basado en D&D 5e, hecho en JavaScript.

## Instalación
Requiere Node.js. Luego:
```
npm install
```

## Uso
```
node src/index.js <personaje> <enemigo>
```
Personajes: carlos, krouds, mirrir. Enemigos: goblin, esqueleto, lobo, orco.

Ejemplo: `node src/index.js krouds orco`

## Modo Manual

node src/index.js <personaje> <enemigo> --manual
